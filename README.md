# VintaGamer – vydania / releases

Tu sú hotové vydania konzoly **VintaGamer** (retro hry pre dvoch na starých
počítačoch). Nahrávajú sa sem automaticky; zdrojový kód je v súkromnom
repozitári `jano-g/VintaGamer`.

Ready-made releases of the **VintaGamer** console. They are published here
automatically; the source code lives in a private repository.

## Stiahnutie / Download

**[Releases](https://github.com/jano-g/VGupdater/releases/latest)** →

| Súbor | Na čo |
|-------|-------|
| `vintagamer-vX.Y.Z.iso` | zapíš na USB kľúč (balenaEtcher, Rufus v režime DD, `dd`) a nabootuj |
| `vintagamer-games-vX.Y.Z.squashfs`, `vintagamer-base-*.tar`, `vintagamer-update.txt` | aktualizácie, ktoré si nainštalovaná konzola stiahne sama (zvyčajne len pár MB) |
| `vintagamer-web-vX.Y.Z.zip` | hry v prehliadači |

Nainštalovaná konzola sa aktualizuje cez *Nastavenia → Aktualizácia z
internetu* – berie najnovšie vydanie z tohto repozitára.

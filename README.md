# VinCon – vydania / releases

Tu sú hotové vydania konzoly **VinCon** (retro hry pre dvoch na starých
počítačoch). Nahrávajú sa sem automaticky; zdrojový kód je v súkromnom
repozitári `jano-g/vincon`.

Ready-made releases of the **VinCon** console. They are published here
automatically; the source code lives in a private repository.

## Stiahnutie / Download

**[Releases](https://github.com/jano-g/vcupdater/releases/latest)** →

| Súbor | Na čo |
|-------|-------|
| `vincon-vX.Y.Z.iso` | zapíš na USB kľúč (balenaEtcher, Rufus v režime DD, `dd`) a nabootuj |
| `vincon-update-vX.Y.Z.tar` | aktualizácia, ktorú si nainštalovaná konzola stiahne sama |
| `vincon-web-vX.Y.Z.zip` | hry v prehliadači |

Nainštalovaná konzola sa aktualizuje cez *Nastavenia → Aktualizácia z
internetu* – berie najnovšie vydanie z tohto repozitára.
